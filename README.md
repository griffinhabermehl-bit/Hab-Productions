# Hab Productions

Film, photography, and FPV portfolio for Griffin Habermehl.

Published with GitHub Pages from the `main` branch root.

Only `index.html`, `.nojekyll`, and `assets/` are needed for hosting. Portfolio films retain their finished audio and offer native playback controls. The inquiry form opens the visitor’s email app; the visitor reviews and sends the email.


## Gallery

The Gallery section includes 12 photographs and five short films, with traditional color and light corrections. Photos use responsive WebP exports and an enlarged viewer; videos use H.264 MP4 with original durations and any source audio. Videos load on demand.

The original SSD media is unchanged. Full-resolution corrected JPEGs are saved locally in `Hab Productions/corrected-media/`. Adjustment settings, source mapping, and before/after review sheets are saved locally in `Hab Productions/review/gallery/`; these local files are not uploaded to the public repository.
